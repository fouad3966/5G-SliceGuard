Data Plane (Deep Packet Inspection): AI inspects the actual data payloads in real-time to spot malicious signatures.

Control Plane (SDN + AI): The Software-Defined Networking controller uses AI to look at the "big picture" of traffic routing. If it sees suspicious patterns moving between slices, it dynamically rewrites flow rules to block those specific packets.

Management Plane (NFV): It uses Network Function Virtualization to instantly spin up "virtual firewalls" or Intrusion Detection Systems and drop them exactly where a slice is under attack.
